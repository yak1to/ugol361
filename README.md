# Угол 361 — сайт барбершопа и шаблон

Одностраничник + страница цен для барбершопа «Угол 361» (Москва, м. Профсоюзная).
Весь контент и бренд лежат в одном конфиге, поэтому следующий салон собирается за вечер.

Стек: Astro 7 · TypeScript · GSAP (ScrollTrigger, SplitText, MotionPath) · Lenis · ванильный CSS.

```bash
npm install
npm run dev       # http://127.0.0.1:4321
npm run build     # статика в dist/
npm run preview   # проверить сборку
```

Страницы: `/` — сайт, `/prices` — цены, `/pitch` — экран для владельца (noindex), `/styleguide` — токены и компоненты (noindex).

## Как перекрасить под другой салон

Компоненты не трогаем. Меняются только файлы ниже.

### 1. `src/config/site.ts` — всё содержимое
| Поле | Что это |
|---|---|
| `name`, `nameLatin`, `kind` | Название и тип заведения |
| `address` | Город, улица, подсказка («вход через цветочный»), метро, расстояние, `geo` (координаты из карточки в Яндекс Картах) |
| `phone`, `hours`, `booking`, `socials` | Контакты. `booking.href` — ссылка на онлайн-запись |
| `rating` | Оценка, число оценок и отзывов, ссылка на отзывы |
| `prices` | Услуги, цены, цена первого визита, акция-стикер |
| `features` | Удобства в бегущей строке. `id` = имя файла стикера |
| `hero`, `door`, `manifesto`, `footer` | Тексты секций |
| `lookbook` | Фото работ: файл, подпись, alt |
| `barbers`, `reviews`, `reviewTopics` | Мастера, реальные отзывы, темы отзывов |
| `route`, `mapEmbed`, `mapRoute`, `mapOrg` | Шаги маршрута и ссылки на Яндекс Карты |
| `theme.colors`, `theme.fonts` | Палитра и шрифты. Из них собираются CSS-переменные |

Виджет карты на карточке организации:
`https://yandex.ru/map-widget/v1/org/<slug>/<id>/?ll=<lon>%2C<lat>&z=17`
(slug и id берутся из ссылки на карточку).

### 2. Фото — `src/assets/photos/raw/`
Имена файлов должны совпадать с теми, что указаны в `site.ts`. Форматы AVIF/WebP и `srcset` Astro собирает сам.
`ornament-tile.jpg` — фоновый орнамент фасада. Его можно заменить на текстуру бренда или убрать.

### 3. Два SVG — `src/assets/svg/`
- `logo.svg` — логотип. Классы `lg-u`, `lg-g`, `lg-dial`, `lg-l` нужны для анимации по буквам. Если логотип другой, оставьте `lg-dial` на круге, который крутится в прелоадере.
- `window.svg` — «окно» со стены. Цвета задаются CSS-переменными `--win-fill`, `--win-hot`, `--win-frame`.
- `stickers/*.svg` — стикеры удобств. Их можно перегенерировать скриптом в своём стиле или нарисовать заново.

Схема маршрута (`src/components/sections/FindUs.astro`) рисуется под конкретное место. У другого салона поменяйте вывеску и дверь.

### 4. Шрифты
Заголовки — Oswald (замена Druk Cyr), цифры — Playfair Display Italic, текст — Onest. Подключение и наборы символов — в `src/layouts/Base.astro`.

## Анимации
`src/scripts/motion/` — по модулю на эффект: прелоадер и хиро (`intro.ts`), окна и манифест (`windows.ts`), лукбук (`lookbook.ts`), счётчик градусов, рейтинг и промо (`counter.ts`), бегущая строка, магнит и курсор (`pointer.ts`), маршрут (`route.ts`).
Режимы переключаются через `gsap.matchMedia()`. На десктопе работают пины, курсор и магнит. На мобайле обычный скролл и свайп. При `prefers-reduced-motion` анимаций нет, сразу показываются финальные состояния.
